## About me

I'm a developer interested in how the pieces of a system fit together: the interface people use, the API behind it, the data it stores, and the tests that check its behaviour. My projects span **full-stack web development**, **native and cross-platform apps**, and **machine learning / signal processing**.

- 🌐 Building **Worldline**, a reading app with React, TypeScript, Django REST Framework and PostgreSQL.
- 📱 Working across **Swift / UIKit / SwiftUI** and **Kotlin / Compose Multiplatform**, from persistent app data to reusable UI and animations.
- 🧠 Exploring **PyTorch-based intrusion detection** and **Python-based EEG analysis**.

## Things I've been building

### 🌐 [Worldline](https://github.com/Areca293/worldline)

**Full-stack reading app · In development**  
`React` `TypeScript` `Vite` `TanStack Query` `Django REST Framework` `PostgreSQL` `Docker`

A mobile-first reading app for technology, economy, finance and music. The current scaffold connects a React interface to a Django API, with article models, topic filtering, admin tools and a local PostgreSQL setup.

Includes frontend and backend tests for error handling and data states. The current version uses sample articles; PostgreSQL acceptance checks and live feeds are still ahead.

### 📱 [Liverpool Squad](https://github.com/Areca293/Liverpool-Squad)

**Native iOS squad manager**  
`Swift` `UIKit` `Core Data` `WebKit`

An iOS app with player CRUD, favourites, photos and persistent storage. Uses `NSFetchedResultsController` for data-driven UI updates, XML for initial data, and `WKWebView` for linked player information.

### 🧠 [HybridVAE](https://github.com/Areca293/HybridVAE)

**Machine learning for network intrusion detection**  
`Python` `PyTorch` `scikit-learn` `pandas` `Jupyter`

A notebook-based intrusion detection project using CIC-IDS-2017 data, with model experiments, data analysis and visualisation. The repository includes the notebook, report and presentation.

### 🗺️ [TripWave / CodeWave](https://github.com/Areca293/CodeWave)

**Ireland travel planner · Team project**  
`Nuxt 3` `Vue` `Vuetify` · Team backend: `Node.js` `Express` `PostgreSQL`

My contributions focused on UI/UX and the recommendation experience: Figma designs, API-connected suggestions, and an in-page details drawer that keeps the map in view.
